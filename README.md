# 🚀 TaskFlow – Task Management Application

TaskFlow is a full-stack task management application designed to help users organize, track, and manage their daily tasks efficiently. It provides a clean UI, secure authentication, and powerful task management features.

---

## ✨ Features

### 🔐 Authentication
- User registration and login
- Secure authentication using JWT
- Persistent login with token storage
- Protected routes for authenticated users

### 📋 Task Management
- Create, edit, and delete tasks
- Mark tasks as completed or pending
- Set task priority (Low, Medium, High)
- Add task descriptions and due dates

### 📊 Task Organization
- Separate views for:
  - Pending tasks
  - Completed tasks
- Task sorting:
  - Newest first
  - Oldest first
  - By priority

### 📈 Dashboard
- Overview of all tasks
- Statistics:
  - Total tasks
  - Completed tasks
  - Pending tasks
  - Completion rate
- Recent activity tracking

### 👤 User Profile
- Update name and email
- Change password securely
- Avatar generation for users

### 🎨 UI/UX
- Responsive design for all devices
- Clean and modern interface
- Smooth transitions and interactive elements
- Intuitive navigation with sidebar and navbar

### ⚡ Performance & Architecture
- Optimized React components with hooks
- Efficient state management
- Modular and reusable component structure
- RESTful API integration
